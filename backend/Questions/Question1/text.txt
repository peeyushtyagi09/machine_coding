Task management REST API

2. User can create, update, delete and fetch tasks.

.title
.description
.status -> todo, in-progress, completed
priority -> low, medium, high
duedate
createAt

User should only be able to access their own tasks. 
Support:
.pagination
.filtering by status
.filtering by priority
.sorting by due date. 

.proper HTTP status codes. 
.Centrailzed error handling.
